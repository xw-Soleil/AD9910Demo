# ModelProbe-25G

2025年全国大学生电子设计竞赛 G题 - 电路模型探究装置

## 项目简介

基于STM32F407微控制器的电路模型分析系统，具备已知电路控制和未知电路学习建模功能。

## 主要功能

### 已知模型控制
- 根据目标输出频率(100Hz-3kHz)和电压(1-2V)反算输入电压
- 通过传递函数H(s)精确控制DDS输出
- 输出相对误差小于5%

### 未知模型学习
- 自动扫频(1kHz-500kHz)获取电路幅频响应
- 基于LM算法识别滤波器类型(低通/高通/带通/带阻)
- 提取关键参数(k, f0, Q)
- 数字IIR滤波器模拟电路响应，相对误差小于10%

## 系统组成

### 硬件
- **主控**: STM32F407ZGT6
- **信号源**: AD9910 DDS模块
- **采样**: STM32板载ADC (12位，最高2.4MSPS)
- **输出**: STM32板载DAC + 精密运放电路
- **模拟电路**: 已知模型二阶低通滤波器(Sallen-Key结构)

### 软件
- 传递函数反算算法
- Levenberg-Marquardt参数拟合
- 数字IIR滤波器实现
- 自动扫频控制

## 编译环境

- STM32CubeIDE 1.8.0+
- ARM GCC工具链
- STM32HAL库

## 使用说明

1. **硬件连接**: 按照电路图连接DDS模块、ADC输入、DAC输出
2. **编译下载**: 使用STM32CubeIDE编译并下载到开发板
3. **已知模型模式**: 设置目标频率和电压，系统自动计算并输出
4. **学习模式**: 连接待测电路，启动学习，系统自动扫频建模
5. **模拟模式**: 输入信号，系统输出对应的模拟响应
